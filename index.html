この構成での確認事項（設計上、先に潰しておく点）

① Copilot Studio から BigQuery への接続方式
Power Platform には Microsoft 純正の BigQuery コネクタがありません。公開されているのは独立発行元（Independent Publisher）のプレビュー版で、用意されているアクションはデータセット情報の取得のみです。 実装は カスタムコネクタ（BigQuery REST API）、または Power Automate の HTTP アクション経由のいずれかになります。どちらもプレミアムライセンスが前提です。 ＜出典：Microsoft Learn / Connectors 　※接続方式は要件定義フェーズで実機検証します＞
② SharePoint リストの容量
1つのリストに保存できるのは 3,000万件までですが、1つのビューで扱える件数は 5,000件のしきい値があり、SharePoint Online では変更できません。 そのため顧客マスタそのものをリストに置くことはできません。マスタは BigQuery、SharePoint リストは営業の活動記録、という切り分けにしています。 ＜出典：Microsoft サポート「大きいリストとライブラリのリスト ビューのしきい値」＞
③ Microsoft 365 Copilot（有料版）との関係
有料版 Copilot が扱うのは Microsoft Graph 上のデータ（メール・会議・ファイル等）です。BigQuery は Graph の対象外のため、有料版を購入しても今回のデータ照会は実現しません。今回作るのは Copilot Studio 上の専用エージェントです。

営業データアシスタント公開済み

概要

エージェントの動き方・参照先・使える操作を、この1画面で管理します

説明

エージェントが何をするものかの説明（オーケストレーションの判断にも使われます）
統合データベースに蓄積された顧客・契約・使用量・保安点検のデータを参照し、営業担当からの日本語の質問に対して、集計結果と根拠を返します。

手順（指示）

エージェントの振る舞いを決める指示文。営業所への展開時はここをコピーして所ごとに調整します
・回答は必ず統合データベースの集計結果のみに基づくこと。推測で数値を補わない。 ・該当データが無い場合は「該当なし」と答え、件数をゼロと言い換えない。 ・件数を答えるときは、集計に使った条件（期間・対象・除外）を必ず併記する。 ・ログインユーザーの営業所コードの範囲外のデータは参照しない。 ・金額に関する項目は、参照権限のあるユーザーにのみ提示する。 ・個人の氏名・連絡先は出力せず、顧客IDで示す。 ・回答の末尾に、参照したテーブル名を必ず列挙する。
