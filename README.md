# 統合データベース × Microsoft 365 AI活用デモ（匿名版）

統合データベース（Google BigQuery 想定）に集まった顧客・契約・使用量データを、
**Microsoft 365 側の3つの入口（Power BI / Copilot Studio / SharePoint リスト）から使う**構成の操作デモです。
各画面は実製品のUIを模して作成しています。株式会社デジライズ作成。検索インデックス除外（noindex）。

## 役割の切り分け（デモの主張）

- **見る＝Power BI**：毎月見る定型の数字。BigQuery のネイティブコネクタで接続（Import / DirectQuery 両対応、Entra ID SSO 可）
- **聞く＝Copilot Studio**：レポートに無い切り口を日本語で取り出す
- **書く＝SharePoint リスト**：訪問記録・案件メモ。見送った CRM の代わりに、入力項目を絞った軽量な受け皿

## 権限による出し分け

| ユーザー | 行 | 金額列 |

## 設計上の確認事項（画面内にも明記）

1. **Copilot Studio → BigQuery の接続方式**
   Power Platform に Microsoft 純正の BigQuery コネクタはありません。公開されているのは独立発行元（Independent Publisher）のプレビュー版で、アクションはデータセット情報の取得のみです。
   実装は**カスタムコネクタ（BigQuery REST API）**または **Power Automate の HTTP アクション経由**になります（いずれもプレミアム）。
   → 要件定義フェーズで実機検証が必要。
2. **SharePoint リストの容量**
   1リストの保存上限は3,000万件ですが、**1ビューあたり5,000件のしきい値があり SharePoint Online では変更できません**。
   顧客マスタはリストに置けないため、マスタは BigQuery、リストは活動記録、と分けています。
3. **Microsoft 365 Copilot（有料版）との関係**
   有料版が扱うのは Microsoft Graph 上のデータです。BigQuery は Graph の対象外のため、有料版の購入では今回のデータ照会は実現しません。
