# 統合データベース AI活用コンソール デモ（匿名版）

統合データベース（BigQuery想定）に集まった顧客・契約・使用量データに対して、
**営業現場が日本語で質問すれば集計結果が返る**状態をつくり、その利用状況を
**推進側が管理・計測する**ための管理コンソールの操作デモです。
株式会社デジライズ作成。検索インデックス除外（noindex）。

- `index.html` … デモ本体（自己完結・外部依存なし）

## デモで見せているもの

1. **ダッシュボード**
   - 稼働中のAIマスター数／今月の質問数／削減時間（試算）／展開済み営業所
   - 質問数の推移、エージェント別の利用比率、直近のアクティビティ
   - 「回答できなかった質問」「今月まだ利用のないAIマスター」など、推進側が手を打つべき項目

2. **AIデータ照会（現場が使う画面）**
   - 4つの質問シナリオ：解約×新料金対象の件数／優先訪問先の抽出／前年同期比の集計／提案トークの骨子
   - 回答までの実行ステップ（質問解析 → 権限判定 → 統合DB照会 → 集計）を可視化
   - 回答には必ず**参照したテーブル**を表示し、AIが生成したSQLを開いて確認できる

3. **権限による出し分け（本デモの要点のひとつ）**
   - 画面右上でログインユーザーを切り替えると、**同じ質問でも回答が変わる**
     - 本社マーケティング部 → 全営業所・全項目
     - 営業所AIマスター → 自営業所の行のみ（他営業所は検索段階で除外）
     - 営業担当 → 自営業所の行のみ＋**金額に関する列は非表示**、管理メニューも非表示
   - 権限は「AIへのお願い（プロンプト）」ではなく、**検索時のフィルタ**として実装する設計

4. **エージェント管理**
   - 4つの標準エージェント（顧客データ照会／優先アプローチ抽出／提案トーク生成／報告・資料作成）
   - 公開範囲・参照テーブル・出力形式・利用制限・**AIへの指示文（プロンプト）**を一覧で管理
   - 公開／停止のトグル、最終更新と今月の利用件数

5. **営業所・AIマスター管理**
   - 16営業所の展開状況（AIマスター人数・登録ユーザー・利用率・最終利用日・状態）
   - 「順調／フォロー要／立ち上げ中」でのフィルタ

6. **利用状況・効果測定**
   - 営業所別の利用率、質問カテゴリの内訳、削減時間の試算（前提を画面上に明記）
   - **回答できなかった質問（改善候補）**を原因分類・対応方針つきで一覧化

7. **データソース連携**
   - AIが直接触るのは統合データベースのみ。基幹システムには変更を加えない構成
   - 参照テーブルごとの更新頻度と権限の扱い（案）

## 注意

- 表示される営業所名・顧客ID・数値・日付はすべて**架空のサンプル**です。実データは含まれていません。
- 本デモはUIシミュレーションであり、実際のBigQuery／基幹システムには接続していません。
- 参照テーブルの構成・更新頻度・権限の扱いは「案」であり、確定には統合データベースの仕様確認が必要です。
- 削減時間は「1件の質問＝従来15分のデータ収集・加工に相当」という前提での試算値です。
